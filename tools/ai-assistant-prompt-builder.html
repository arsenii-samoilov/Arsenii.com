I use this shape every day: a one-page system prompt for who I am, plus a six-block task template for each request. Fill in the fields, copy the output into ChatGPT, Claude, or your IDE, and you have a working executive assistant setup in minutes.

How to set up your AI executive assistant

  1. Copy the system prompt into a ChatGPT project, Claude project, or rules file in your IDE.
  2. When you have real work, open the task template, paste your notes where indicated, and send it.
  3. When output misses, fix the prompt (usually Context or Output format), not the model brand.
  4. After a week, save your best variants. That library becomes your personal playbook.

For the full walkthrough, read Setting Up an AI Executive Assistant. For enterprise rollout, see the AI program management hub.

The six-block task shape

  • Role who the model should be for this request
  • Context minimum background, paste notes here
  • Task the single outcome you need
  • Constraints what to avoid or never assume
  • Output format length, bullets, table, or draft
  • Quality bar how you will judge success

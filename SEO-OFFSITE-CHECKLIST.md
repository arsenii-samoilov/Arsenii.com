# Off-Site SEO Checklist (Reference Only)

Practical, skimmable list for earning backlinks to the free tools and syndicating a few Insights articles. Nothing here is pushed automatically. Work top to bottom, one or two submissions a week, and keep the tone helpful rather than promotional.

Primary tools hub to promote: https://arsenii.com/tools/

---

### Submission hygiene
- Vary the anchor text (e.g. "free RACI matrix generator," "program risk register tool," "TPM tools").
- Submit the deep tool URL where it fits the audience, the hub where it does not.
- Never post the same link to multiple subreddits the same day.
- Track each submission (date, site, link used, status) in a simple sheet so you do not double-post.

## Part 2: Syndication plan (repost with rel=canonical back to arsenii.com)

Repost 3-4 Insights articles to Medium, dev.to, and LinkedIn. Always set the canonical to the arsenii.com original so search engines credit the source, not the copy. On Medium use the Import Story tool (it sets canonical automatically). On dev.to set the `canonical_url` field in the post settings. On LinkedIn articles, link prominently back to the original in the first and last paragraph (LinkedIn does not expose a canonical tag).

| Article | Canonical URL to use | Why it travels well |
|---------|----------------------|---------------------|
| Project Manager vs. Technical Program Manager | https://arsenii.com/insights/project-manager-vs-technical-program-manager.html | Evergreen, high-search topic; pairs with the new comparison page. Great LinkedIn performer. |
| How to Write a Status Report Executives Actually Read | https://arsenii.com/insights/status-report-executives-actually-read.html | Tactical and widely useful; strong saves and shares on LinkedIn and Medium. |
| Managing Dependencies Across Eight Engineering Teams | https://arsenii.com/insights/managing-dependencies-eight-teams.html | Credibility piece; resonates with senior TPM and eng-lead audiences on dev.to. |
| Decision Logs: The Most Underrated Tool in Program Management | https://arsenii.com/insights/decision-logs-underrated-tpm-tool.html | Contrarian, specific, easy to act on; good Medium and Indie Hackers fit. |

### Syndication hygiene
- Wait until the original has been indexed on arsenii.com before syndicating (check Search Console).
- Set the canonical on every repost without exception.
- Add one contextual link from each repost to a relevant free tool or pillar guide (e.g. the status report article links the status report generator).
- Stagger reposts a week or two apart so you are not flooding the same audience.
